\f0\fs24 \cf0 # Fase 2: Define (Kaders & Probleemstelling)\
\
## 1. De Probleemstelling (Point of View)\
\
Generatie Z heeft een manier nodig om makkelijker en leuker te leren koken, omdat veel jongeren steeds minder zelf koken en vaker kiezen voor fastfood, afhaalmaaltijden en kant-en-klaar eten. Hierdoor eten ze minder gezond en ontwikkelen ze minder kookvaardigheden.\
\
## 2. Programma van Eisen (MoSCoW)\
\
### Must Haves\
\
- [ ] De website moet responsive zijn (Mobile First).\
- [ ] Gebruikers moeten recepten kunnen bekijken.\
- [ ] Gebruikers moeten recepten kunnen toevoegen, aanpassen en verwijderen.\
- [ ] Gebruikers moeten zich kunnen registreren en inloggen.\
- [ ] Er moet een zoekfunctie aanwezig zijn voor recepten.\
- [ ] De website moet gebruikmaken van een database.\
- [ ] Er moet een beheerder zijn die recepten en gebruikers kan beheren.\
\
### Should Haves\
\
- [ ] Recepten bevatten foto's.\
- [ ] Gebruikers kunnen favoriete recepten opslaan.\
- [ ] De website heeft een moderne uitstraling die Generatie Z aanspreekt.\
- [ ] Gebruikers kunnen recepten filteren op categorie.\
- [ ] Gebruikers kunnen kooktips delen.\
\
### Won't Haves (Buiten scope)\
\
- [ ] Integratie met echte supermarkt API's.\
- [ ] Online bestellen van boodschappen.\
- [ ] Een mobiele app.\
- [ ] Chatfunctie tussen gebruikers.\
- [ ] Koppelingen met betaalmethoden.}
